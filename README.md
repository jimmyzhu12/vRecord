# vRecord Dataset

This repository hosts the dataset associated with the paper **_vRecord: A User Study Dataset on Video Watching Behavior_**.

Comprehensive details regarding the dataset, including its collection process, structure, and analysis, are available in the accompanying paper.

## Current Release

This repository is intended to be updated continuously.
The current release contains the data collected during **2025**, corresponding exactly to the dataset discussed in the paper.

## Reference

For a detailed description and analysis of the dataset, please consult the paper.
